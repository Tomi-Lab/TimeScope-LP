支援與常見問題（FAQ）

關於安裝、自訂設定與使用 TimeScope – Visual Calendar v1.2.0 的說明。

安裝與系統相容性

支援哪些 Windows 版本？

TimeScope v1.2.0 專為 Windows 10 與 Windows 11 (x64) 打造，並透過 Microsoft Store 發佈。

啟動 TimeScope 後找不到圖示怎麼辦？

TimeScope 執行於 Windows 系統匣。若圖示位於隱藏圖示選單 (▲) 內，可拖曳至工作列，或前往「Windows 設定 → 個人化 → 工作列 → 其他系統匣圖示」開啟顯示。

行事曆顯示與日期區間選取

一次最多可以顯示幾個月份？

您可依可用視窗與螢幕空間自由橫向與縱向擴展顯示，沒有固定的 6 個月上限。

如何計算兩個日期之間的天數？

在行事曆上拖曳選取任意日期，所選期間會立即反白，並在浮動標籤與底部摘要列中顯示精確天數（支援跨月）。

如何變更縮放大小、每週起始日或語言？

開啟行事曆選單即可切換 Small、Medium、Large 三種字體大小預設、週日或週一起始日、ISO 週數與相對天數 (-n / +n)，並免重新啟動即時切換 7 種語言。

TimeScope Pro 與購買

TimeScope Pro 包含哪些功能？

TimeScope Pro 為可選的一次性應用程式內購買（基準價格 $4.99 USD，實際幣別與稅率依地區而異，無需訂閱），可解鎖多區間比較、多螢幕顯示選擇與自訂節假日與工作日。

重新安裝後如何購買或還原 TimeScope Pro？

TimeScope Pro 透過應用程式內的 Microsoft Store 購買機制綁定您的 Microsoft 帳戶。若在購買或還原授權時遇到任何問題，請附上 Microsoft Store 訂單資訊聯繫 support@gettimescope.com。
