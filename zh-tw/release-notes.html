查看 TimeScope 的版本歷史與最新改進。

v1.2.2 (2026-11-20)

  • 修正於 Microsoft Store 購買或兌換 TimeScope Pro 後，在恢復購買或重啟同步時可能無法辨識的問題。
  • 包含 v1.2.1 的所有改進（開機自動啟動修正、Windows 啟動設定同步、Pro 按鈕與更新檢查最佳化）。

v1.2.1 (2026-11-19)

  • 修正「登入時啟動」功能，重新開機或登入後 TimeScope 會自動啟動。
  • 與 Windows 設定中的啟動狀態保持同步，並尊重使用者在 Windows 中的停用選擇。
  • 將「關於」視窗中的 Pro 引導連結改為更清晰的按鈕。
  • 修正「關於」視窗中點擊檢查更新時失敗的問題。

v1.2.0 (2026-11-03)

  • 向 Free 版免費開放多欄橫向日曆擴展檢視。
  • 全面支援 7 種語言（英語、日語、簡體/繁體中文、德語、法語、西班牙語）。
  • 依據所選語言最佳化月份、星期與日期格式。
  • 簡化為清晰的 Free 與 Pro 雙層級架構，並支援 Microsoft Store。
