支持与常见问题（FAQ）

关于安装、自定义设置以及使用 TimeScope – Visual Calendar v1.2.0 的说明。

安装与系统兼容性

支持哪些 Windows 版本？

TimeScope v1.2.0 适用于 Windows 10 和 Windows 11 (x64)，通过 Microsoft Store 分发。

启动 TimeScope 后找不到图标怎么办？

TimeScope 在 Windows 系统托盘中运行。若被收纳在隐藏图标菜单 (▲) 中，可将其拖至任务栏，或在“Windows 设置 → 个性化 → 任务栏 → 其他系统托盘图标”中开启常驻显示。

日历视图与日期范围选择

一次最多可以显示几个月份？

您可以根据可用窗口和屏幕空间横向与纵向扩展显示，没有固定的 6 个月上限。

如何计算两个日期之间的天数？

在日历上按住并拖动任意日期，所选期间会立即高亮，并在浮动标签与底部摘要栏中显示准确天数（支持跨月）。

如何更改缩放大小、每周起始日或语言？

打开日历菜单即可选择 Small、Medium、Large 三种缩放预设，切换周日或周一起始日、ISO 周数与相对天数 (-n / +n)，或免重启即时切换 7 种语言。

TimeScope Pro 与购买

TimeScope Pro 包含哪些功能？

TimeScope Pro 为可选的一次性应用内购买（基准价格 $4.99 USD，实际币种与税费因地区而异，无需订阅），可解锁多区间对比、多显示器显示选择及自定义节假日与工作日。

重装系统后如何购买或恢复 TimeScope Pro？

TimeScope Pro 通过应用内的 Microsoft Store 应用内购买绑定至您的 Microsoft 账户。如在购买或恢复授权时遇到问题，请附带 Microsoft Store 订单信息联系 support@gettimescope.com。
