发行说明

查看 TimeScope 的版本历史与最新改进。

v1.2.2 (2026-11-20)

  • 修复在 Microsoft Store 购买或兑换 TimeScope Pro 后，恢复购买或重启同步时可能无法识别的问题。
  • 包含 v1.2.1 的全部改进（开机自启修复、Windows 启动设置同步、Pro 按钮及更新检查优化）。

v1.2.1 (2026-11-19)

  • 修复“登录时启动”功能，重启电脑或重新登录后 TimeScope 可自动启动。
  • 与 Windows 设置中的启动状态保持同步，并尊重用户在 Windows 中的关闭选择。
  • 将“关于”窗口中的 Pro 引导链接更换为更醒目的按钮。
  • 修复“关于”窗口中点击检查更新时失败的问题。

v1.2.0 (2026-11-03)

  • 向 Free 版免费开放多列横向日历扩展视图。
  • 全面支持 7 种语言（英语、日语、简体/繁体中文、德语、法语、西班牙语）。
  • 根据所选语言本地化月份、星期与日期格式。
  • 简化为清晰的 Free 与 Pro 两档模式，并接入 Microsoft Store。
