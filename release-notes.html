v1.2.2 (2026-11-20)

  • Fixed an issue where purchased or redeemed TimeScope Pro licenses could fail to be recognized when restoring or syncing from the Microsoft Store.
  • Includes all v1.2.1 improvements ("Start at login" fix, Windows Startup settings sync, clearer Pro button, and update checker fix).

v1.2.1 (2026-11-19)

  • Fixed "Start at login" so TimeScope launches reliably when you sign in or restart your PC.
  • Synced startup state with Windows Settings (Apps -> Startup) and respected user disable settings.
  • Replaced the subtle Pro link in the About dialog with a clearer button.
  • Fixed an issue where checking for updates in the About dialog failed.

v1.2.0 (2026-11-03)

  • Unlocked multi-column horizontal calendar expansion for everyone in the Free edition.
  • Added full support for 7 languages (English, Japanese, Simplified & Traditional Chinese, German, French, Spanish).
  • Localized month names, weekday headers, and date formats.
  • Simplified into clear Free and Pro tiers with Microsoft Store integration.
