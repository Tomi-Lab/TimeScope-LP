サポート・よくある質問（FAQ）

TimeScope – Visual Calendar の導入・カスタマイズ・Pro 版に関するご案内です。

インストール・動作環境

対応している Windows のバージョンは？

TimeScope は Windows 10 および Windows 11（x64）に対応しており、Microsoft Store から配布されています。

起動したのにアイコンが見当たりません。

TimeScope は Windows システムトレイで動作します。隠れたインジケーター（▲）内に格納されている場合は、タスクバーへドラッグするか、「Windows 設定 → 個人用設定 → タスクバー → その他のシステム トレイ アイコン」で表示を有効にしてください。

カレンダー表示・期間選択

最大で何か月まで表示できますか？

ウィンドウや画面の空き領域に合わせて横方向・縦方向に自由に拡張でき、6か月などの固定上限はありません。

2つの日付の間の日数を調べるには？

カレンダー上で日付をドラッグすると選択範囲が強調表示され、フローティングバッジと下部サマリーに正確な日数が即座に表示されます（月をまたぐ期間にも対応）。

ズームサイズ・週の開始曜日・言語を変更するには？

カレンダーメニューから Small / Medium / Large の3段階ズーム、日曜／月曜始まり、ISO 週番号や相対日数（-n / +n）の表示、再起動なしの7言語切り替えを行えます。

TimeScope Pro・ご購入について

TimeScope Pro には何が含まれますか？

TimeScope Pro は買い切りのアプリ内購入（基準価格 $4.99 USD／地域により現地通貨・税込価格が異なります、サブスクリプションなし）で、マルチバンド比較、マルチモニター表示先選択、カスタム休日・稼働日設定をアンロックします。

購入や再インストール後のライセンス復元はどうすればよいですか？

TimeScope Pro はアプリ内の Microsoft Store アプリ内購入を通じて Microsoft アカウントに紐づきます。再インストール後の復元や購入時に問題が発生した場合は、Microsoft Store の注文情報とあわせて support@gettimescope.com までご連絡ください。
